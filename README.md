# Kratos — Rutina Full Body PWA

Aplicación Web Progresiva (**PWA**) instalable en dispositivos móviles y escritorio para seguimiento de rutinas de entrenamiento **Full Body**, control de series/cargas y persistencia local offline.

- **Demo en vivo (GitHub Pages):** [https://isandalusi.github.io/rutina-gym/](https://isandalusi.github.io/rutina-gym/)

---

## Características Principales
- **PWA Instalable (`manifest.json`):** soporte de modo `standalone`, íconos dedicados y experiencia tipo app móvil.
- **Funcionamiento Offline:** Service Worker + almacenamiento en `localStorage` con preservación de datos entre actualizaciones.
- **Diseño Mobile-First:** interfaz responsive orientada a uso rápido durante sesiones de entrenamiento.

---

## Stack Tecnológico
- **Frontend:** HTML5, CSS3, JavaScript Vanilla (ES6+)
- **Capacidades PWA:** Web App Manifest & Service Worker
- **Persistencia:** Web Storage (`localStorage`)
- **Deploy:** GitHub Pages
